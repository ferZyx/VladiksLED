VladiksLED is a PlatformIO firmware project for ESP8266 (d1_mini) that drives LED garland and backlight effects with a web UI/API. Runtime entrypoint is src/main.cpp with setup()/loop(). Web HTTP/WebSocket API is implemented in src/webserver.cpp, and embedded frontend UI is in src/webpage.h. LED effects are in src/led_modes.cpp and persistent state/EEPROM migration logic is in src/led_state.h/.cpp.

Agent instruction files: AGENTS.md (canonical rules), CLAUDE.md (imports AGENTS.md via @AGENTS.md and adds architecture notes: main loop order, raw-struct EEPROM layout pitfalls, OTA-by-default upload). Keep CLAUDE.md free of duplicates from AGENTS.md.
