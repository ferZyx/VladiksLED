Tech stack: C++ for Arduino/ESP8266 using PlatformIO, FastLED, ESPAsyncWebServer, ArduinoJson, EEPROM. Project is a single firmware module (not monorepo). Key files: src/main.cpp (main loop, mode switching, autoswitch, persistence trigger), src/led_modes.cpp (effects), src/led_state.cpp/.h (state+EEPROM), src/webserver.cpp/.h (API routes/handlers), src/webpage.h (embedded web app), src/config.h (device/network config and constants).
