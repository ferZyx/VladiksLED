# 🎄 WiFi LED Garland - Современная WiFi гирлянда

Проект умной WiFi-гирлянды на базе ESP8266 (Wemos D1 Mini) с красивым веб-интерфейсом на Tailwind CSS.

![WiFi LED Garland](https://img.shields.io/badge/ESP8266-WiFi%20Garland-blue)
![Platform](https://img.shields.io/badge/Platform-PlatformIO-orange)
![Framework](https://img.shields.io/badge/Framework-Arduino-00979D)

## ✨ Возможности

- 🌐 **Веб-интерфейс** - красивый responsive дизайн с Tailwind CSS
- 🎨 **10 режимов** свечения (Огонь, Плазма, Конфетти и др.)
- ☀️ **Управление яркостью** (0-255)
- 💡 **Настройка количества диодов** (1-300)
- ⚙️ **Настройки каждого режима** (скорость, масштаб, цвета)
- 🔄 **Авто-переключение** режимов (по порядку или случайно)
- 💾 **Сохранение настроек** в EEPROM
- 🚀 **Debounce защита** от флуда запросами
- 📱 **Адаптивный дизайн** - работает на телефоне, планшете, ПК

## 📋 Требования

### Железо

- **ESP8266** (Wemos D1 Mini, NodeMCU и т.д.)
- **LED лента** WS2812B (до 300 диодов)
- **Блок питания** 5V (мощность зависит от количества диодов)
- **USB кабель** для прошивки

### Программное обеспечение

- [PlatformIO](https://platformio.org/) (расширение для VS Code или CLI)
- Python 3.x (для PlatformIO)
- VS Code (рекомендуется)

## 🚀 Быстрый старт

### Шаг 1: Клонирование проекта

Проект уже находится в:

```bash
c:\Users\sorok\arduino\VladiksLED
```

### Шаг 2: Настройка WiFi

**ВАЖНО!** Откройте файл `src/config.h` и замените WiFi credentials:

```cpp
// WiFi настройки
#define WIFI_SSID "YOUR_WIFI_NAME"        // <-- Замените на имя вашей WiFi
#define WIFI_PASSWORD "YOUR_WIFI_PASSWORD" // <-- Замените на пароль от WiFi
```

### Шаг 3: Подключение LED ленты

Подключите LED ленту к плате:

| LED лента      | Wemos D1 Mini      | Описание         |
| -------------- | ------------------ | ---------------- |
| **DIN** (Data) | **D4** (GPIO2)     | Сигнальная линия |
| **+5V**        | Внешний БП 5V      | Питание          |
| **GND**        | GND платы + GND БП | Общий минус      |

> ⚠️ **ВАЖНО**: Не питайте длинную ленту от USB! Используйте отдельный блок питания 5V.

**Расчёт мощности БП:**

- 1 диод WS2812B ≈ 60mA (при белом цвете на максимальной яркости)
- 50 диодов ≈ 3A → БП на 5V 3-4A
- 100 диодов ≈ 6A → БП на 5V 6-8A

### Шаг 4: Настройка количества диодов (опционально)

Если у вас не 50 диодов, измените в `src/config.h`:

```cpp
#define DEFAULT_LEDS 50     // <-- Замените на ваше количество
```

### Шаг 5: Компиляция и загрузка

#### Вариант А: Через VS Code с PlatformIO

1. Откройте проект в VS Code:

   ```bash

2. Подключите плату к USB

3. Нажмите кнопку **Upload** (стрелка →) на панели PlatformIO внизу экрана

# Загрузка на плату

### Шаг 6: Подключение к веб-интерфейсу

1. После загрузки откройте **Serial Monitor** (в PlatformIO или через команду `pio device monitor`)

2. Подождите пока плата подключится к WiFi

3. Найдите строку с IP адресом:

   ```

4. Откройте браузер и введите этот IP адрес

5. Готово! 🎉

## 🎨 Как пользоваться веб-интерфейсом

### Главный экран

- **⚡ Питание** - включение/выключение гирлянды
- **☀️ Яркость** - ползунок для регулировки яркости (0-100%)
- **💡 Количество диодов** - укажите реальное количество диодов
- **⚙️ Настройки** - откроет модальное окно с дополнительными настройками

### Режимы свечения

Прокрутите вниз до сетки с режимами. Для каждого режима:

- **Выбрать** - активировать этот режим
- **⚙️** - открыть настройки режима (скорость, масштаб)

### Окно настроек

- **Авто-переключение** - время в секундах между режимами (0 = выкл)
- **Случайный порядок** - режимы будут меняться случайно, а не по порядку

## 🔧 Возможные проблемы

### Не подключается к WiFi

1. Проверьте правильность SSID и пароля в `src/config.h`
2. Убедитесь что WiFi на 2.4GHz (ESP8266 не поддерживает 5GHz)
3. Если плата мигает красным - ошибка подключения, она перезагрузится автоматически

### LED лента не светится

1. Проверьте подключение DIN к пину D4
2. Проверьте питание ленты (5V и GND)
3. Убедитесь что количество диодов установлено правильно
4. Попробуйте увеличить яркость в веб-интерфейсе

### Веб-интерфейс не открывается

1. Найдите IP адрес в Serial Monitor
2. Убедитесь что компьютер/телефон в той же WiFi сети
3. Попробуйте пропинговать: `ping 192.168.1.XXX`

### Не компилируется проект

```bash
# Очистка и пересборка
cd c:\Users\sorok\arduino\VladiksLED
pio run -e d1_mini -t clean
pio run -e d1_mini
```

## 🌐 API Endpoints

Если хотите управлять гирляндой программно:

| Endpoint                  | Method | Body                                 | Описание                   |
| ------------------------- | ------ | ------------------------------------ | -------------------------- |
| `/`                       | GET    | -                                    | Веб-интерфейс              |
| `/api/state`              | GET    | -                                    | Получить текущее состояние |
| `/api/power`              | POST   | `{"on": true/false}`                 | Вкл/выкл                   |
| `/api/brightness`         | POST   | `{"value": 0-255}`                   | Яркость                    |
| `/api/leds`               | POST   | `{"count": 1-300}`                   | Количество диодов          |
| `/api/mode`               | POST   | `{"mode": 0-9}`                      | Выбрать режим              |
| `/api/mode/{id}/settings` | POST   | `{"speed": 0-255, "scale": 0-255}`   | Настройки режима           |
| `/api/auto-switch`        | POST   | `{"delay": секунды, "random": bool}` | Авто-переключение          |

**Пример:**

```bash
# Включить гирлянду
curl -X POST http://192.168.1.100/api/power -d '{"on":true}' -H "Content-Type: application/json"

# Установить яркость 50%
curl -X POST http://192.168.1.100/api/brightness -d '{"value":128}' -H "Content-Type: application/json"

# Выбрать режим Fire (режим 4)
curl -X POST http://192.168.1.100/api/mode -d '{"mode":4}' -H "Content-Type: application/json"
```

## 🎯 Список режимов

0. **Смешанные волны** - плавные переливающиеся волны
1. **Радужная пульсация** - радужные цвета с пульсацией
2. **Две синусоиды** - две волны разной частоты
3. **Конфетти** - случайные яркие вспышки
4. **Огонь** - имитация пламени
5. **Радужный марш** - плавная радужная волна
6. **Плазма** - эффект плазмы
7. **Шум** - динамический шум
8. **Жонглирование** - движущиеся точки
9. **Один цвет** - статичный белый цвет

## 🔐 Безопасность

- Проект имеет **throttle защиту** - максимум 10 запросов в секунду
- Все настройки сохраняются в EEPROM автоматически
- При перезагрузке платы все настройки восстанавливаются

## 🛠️ Дополнительные настройки

### Режимы работы

Гирлянда поддерживает два режима работы:

- **Гирлянда** - динамические эффекты (Огонь, Плазма, Конфетти и др.)
- **Подсветка** - статичное свечение с настраиваемой палитрой цветов

Переключение между режимами происходит в веб-интерфейсе через табы.

### Ожидание синхронизации времени

По умолчанию гирлянда сразу запускает эффекты. Если нужно ждать синхронизации времени (например, для расписаний), измените в `src/config.h`:

```cpp
#define WAIT_FOR_TIME_SYNC false  // false = сразу запускать эффекты
                                  // true = ждать синхронизации (зелёный индикатор)
```

### OTA обновления

Если хотите обновлять прошивку по WiFi (без USB кабеля):

1. В `platformio.ini` уже настроено:

   ```ini
   upload_protocol = espota
   upload_port = 192.168.100.222  # <-- Замените на IP вашей платы
   ```

2. Измените IP на актуальный и загружайте прошивку как обычно

### Увеличение максимального количества диодов

В `src/config.h`:

```cpp
#define MAX_LEDS 300  // <-- Увеличьте если нужно больше
```

> ⚠️ Учтите ограничения по памяти ESP8266!
